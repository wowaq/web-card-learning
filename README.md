# Карточки

Мини-сервер для карточек-коллекций: просмотр, редактирование, фильтры и тренировка со свайпами. Без зависимостей — только стандартная библиотека Python.

## Запуск

```bash
python index.py          # порт 8000
python index.py 5000     # другой порт
```

Браузер откроется сам: `http://127.0.0.1:8000/`. Ctrl+C в терминале гасит сервер.

Требуется Python 3.8+.

## Структура

```
.
├── index.py          # сервер + запуск браузера
├── index.html        # весь фронтенд
├── katex/            # локальный KaTeX (katex.min.css, katex.min.js)
└── collections/
    └── funcan.md     # коллекции — просто md-файлы
```

`index.py`, `index.html` и `collections/` должны лежать рядом. Папка `katex/` — рядом с `index.html`.

## Формат коллекции

Обычный markdown. Шапка между `---`, дальше карточки: строка `# ` — заголовок, `Ответ:` — ответ, `Статус:` — статус.

```markdown
---
name: Функциональный анализ (6 семестр)
created: 2026-10-14
---
# 1. Интеграл Лебега ...
[**Ответ:**] [ ]
[**Статус:** Не запомнил]
# 2. Интеграл Лебега ...
[**Ответ:**] [ ]
[**Статус:** Запомнил]
```

- **Заголовок** — строка, начинающаяся с `# `. Номер в начале (`# 25. ...`) используется для сортировки «по возрастанию».
- **Ответ** — строка, содержащая `Ответ:`. Необязателен; если пусто — в тренировке кнопка «Показать ответ» скрыта. Ответ не должен содержать `]`.
- **Статус** — строка, содержащая `Статус:`. Если её нет, карточка считается «Не запомнил». Сервер сам добавляет строку статуса, если её не было.

Формулы — в `$...$` (строчные) и `$$...$$` (блочные), рендерит KaTeX.

## Возможности

**Просмотр коллекции** — фильтры «Все / Запомнил / Не запомнил», активный подсвечен. Карточка с зелёным или красным градиентом по статусу, кнопка меняет статус и сразу пишет в md. Переключатель вида — сетка или список (сохраняется в localStorage).

**Редактор** — сырой текст md в textarea, сохранение через `PUT`.

**Тренировка** — выбрать одну или несколько коллекций, количество карточек, порядок и статус:

| Порядок | Что делает |
|---|---|
| Случайный | случайные `count` карточек в случайном порядке |
| По возрастанию | случайные `count` карточек, вывод по номеру из заголовка |
| Строгий | карточки по порядку, как в md |

Свайп влево — «не запомнил», вправо — «запомнил». Снизу те же кнопки. Пробел или «Показать ответ» открывает ответ, если он есть. Статус сразу пишется в md.

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/collections` | список коллекций с именем, датой, счётчиками |
| GET | `/api/collections/<file>` | одна коллекция: карточки + сырой текст |
| POST | `/api/collections/<file>/status` | `{index, remembered}` — сменить статус карточки |
| PUT | `/api/collections/<file>` | `{raw}` — перезаписать файл целиком |

Имя файла проверяется: только `[\w\-. ]+\.md`, без путей — обход директории исключён.

## Заметки

- Сервер слушает только `127.0.0.1` — снаружи недоступен. Если нужен доступ из сети, поменяй адрес в `HTTPServer(...)` в `index.py`.
- Файлы читаются и пишутся в UTF-8. Если md сохранён в Windows-1251, сервер упадёт с `UnicodeDecodeError` — пересохрани в UTF-8.
- Статус меняется построчно, остальной файл не трогается.
